# 변경 영향도 분석

## 원칙
- 코드를 고치지 않는다. 분석 대상 폴더 · `db/` 의 파일은 읽기만 한다.
- 모든 항목에 `파일:줄번호` 근거를 단다. 근거를 못 대면 쓰지 않거나 "추적 한계"로 옮긴다.
- 검색으로 찾은 것만 "호출한다"고 쓴다. 이름이 비슷하다는 이유로 호출 관계를 만들지 않는다.

## 1. 대상 정의 찾기
- 인자가 `파일:줄번호` 면 그 줄을 포함하는 함수를, 이름이면 Grep 으로 정의를 찾는다.
- 같은 이름의 정의가 여러 개면(오버로드 · 다른 클래스 · 다른 모듈) 목록을 보여 주고 어느 것인지 묻는다.
- 대상이 속한 모듈을 정한다: `legacy/item-bank-php` → `item-bank`, `legacy/assignment-thymeleaf` → `assignment`, `legacy/grade-mssql` → `grade`.

## 2. 호출부 역추적
- 직접 호출부를 찾는다. 언어별로 검색한다.
  - PHP: `함수명(` · `include` / `require` 한 파일.
  - Java: `.메서드명(` 와 그 메서드를 가진 타입의 주입 지점. 인터페이스 · 상속이면 상위 타입 호출도 찾는다.
  - SQL: `EXEC` · `EXECUTE` · 프로시저 이름, 뷰 · 트리거 · 다른 프로시저 안의 호출, 애플리케이션 코드의 호출 문자열.
  - 템플릿: Thymeleaf `th:` 식, 폼 `action` · 링크 `href`.
- 찾은 호출부를 부르는 곳을 다시 찾고, 진입점(URL 매핑 · 직접 호출되는 PHP 파일 · 배치 · 스케줄러)에 닿을 때까지 반복한다.
- 경로마다 `진입점 → … → 대상` 을 한 줄로 적고, 화살표마다 근거 줄을 단다.

## 3. 데이터 영향
- 대상이 읽고(SELECT) 쓰는(INSERT · UPDATE · DELETE · MERGE) 테이블 · 뷰 · 컬럼을 찾는다. 대상이 부르는 DAO · 하위 함수의 SQL 까지 따라간다.
- 뷰 · 트리거 · FK 는 `db/` 의 스키마 줄까지 확인한다.
- 같은 테이블을 쓰는 다른 함수를 Grep 으로 찾고, 읽기 · 쓰기를 구분한다. 대상이 쓰는 컬럼을 읽는 함수를 먼저 적는다.

## 4. 관련 규칙 연결
- `docs/<모듈명>/BUSINESS-RULES.md` 가 있으면, 근거 줄이 대상 함수 · 호출 경로 · 영향 테이블과 겹치는 규칙 ID 를 연결한다.
- 문서가 없으면 "규칙 문서 없음"이라고 적고 `/document-module` 을 권한다. 규칙을 새로 만들어 쓰지 않는다.

## 5. 추적 한계 점검
검색으로 못 찾는 경로가 의심되면 근거 줄과 함께 "추적 한계"에 따로 적는다.
- PHP 가변 함수 · `call_user_func` · 변수로 만든 `include` 경로.
- Java 리플렉션 · Spring AOP · 이벤트 리스너 · `@Scheduled`, 문자열로 만든 SQL · 뷰 이름.
- SQL 동적 SQL(`sp_executesql`, 문자열 `EXEC`) · 트리거 · 다른 모듈 · 외부 시스템이 같은 DB 를 쓰는 경우.
- 인자로 넘긴 범위 밖에서 호출될 수 있는 public 메서드.

## 6. 출력
아래 순서로 답변한다. 파일은 만들지 않는다(요청하면 `docs/<모듈명>/IMPACT-<대상>.md` 로 저장).

1. **대상:** 정의 위치 `파일:줄번호`, 한 줄 설명.
2. **영향받는 화면:** 표(화면 · URL | 진입점 `파일:줄` | 경로 수).
3. **호출 경로:** `진입점 → … → 대상` 목록. 화살표마다 근거.
4. **영향받는 테이블:** 표(테이블 · 컬럼 | 읽기/쓰기 | 근거 | 같은 테이블을 쓰는 다른 함수 `파일:줄`).
5. **관련 규칙 ID:** `BR-xx` 와 겹치는 근거 줄.
6. **수정 전에 확보할 테스트 케이스:** 관련 규칙 · 분기(조건문 줄)마다 입력 → 기대 결과. 경계값 · 오류 경로 · 같은 테이블을 읽는 다른 화면의 회귀 케이스를 포함한다. 이미 있는 테스트는 파일명을 적는다.
7. **추적 한계:** 5단계 결과. 없으면 "확인한 범위에서 없음"과 검색한 패턴을 적는다.
